# Deepak Chauhan – Interactive Developer Portfolio 🚀

A modern, responsive, multi-page portfolio built for **Deepak Chauhan** with dark/light mode, dynamic particle canvas, interactive developer CLI console, system architecture modals, and verified credentials.

---

```

├── projects.html         # Projects showcase (SAGE AI, FitroniX, Academic Insight, Nekoflix, Chat)

├── contact.html          # Contact channels (+91 7721807761, deepakcchauhan07@gmail.com, direct form)

└── README.md             # Project documentation
```

## ✨ Features Included

1. **Multi-Page Layout (Not crammed into one slide)**:
   - Dedicated pages: **Home**, **About**, **Projects**, **Certifications**, **Contact**.
2. **Upward Direct Contact Bar**:
   - Quick header shortcuts: Email (`deepakcchauhan07@gmail.com`), Phone (`+91 7721807761`), GitHub (`github.com/dc-hub0`), LinkedIn (`linkedin.com/in/deepakxchauhan/`).
3. **Interactive Developer CLI Console**:
   - Type commands like `help`, `about`, `skills`, `projects`, `certs`, `contact`, `clear`.
4. **Command Palette (`Cmd + K` / `Ctrl + K`)**:
   - Instant search and keyboard navigation.
5. **Interactive Project Modals**:
   - View system architecture diagrams, tech stacks, and live GitHub repo links for all 5 resume projects.
6. **Digital Resume Viewer & Print**:
   - Instant 1-click printable resume modal.
7. **Interactive Skills Matrix**:
   - Filterable skills by category (Languages, Frameworks, Databases, Cloud & AI, Tools) with animated progress indicators.
8. **Dark / Light Theme Toggle**:
   - Persistent theme selection stored in `localStorage`.
